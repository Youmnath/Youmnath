## 🚀 Projets et réalisations

### 🚗 BlackBox — Enregistreur de données embarqué en C

Projet de groupe : conservation des **10 dernières secondes** de mesures simulées d'un véhicule (vitesse, température moteur).

- Structures de données : **liste chaînée et buffer circulaire dynamique**
- Gestion mémoire : `malloc`, `calloc`, `free`
- Sauvegarde et lecture de données binaires ; tests de scénarios d'accélération, freinage et surchauffe

🔗 [Consulter mes dépôts]([https://github.com/Youmnath/BlackBoxProject](https://github.com/Youmnath/BlackBoxProject))

### 📊 Power BI — Analyse interactive des ventes

Rapport construit à partir de données de **clients, produits et commandes**, avec analyses par catégorie, produit et ville, dans le cadre de mon apprentissage des fondamentaux Data et de ma préparation à la **DP-900**.

**Outils :** Power BI · préparation et visualisation de données · filtres interactifs.

**Tâche :**
Conception d'un tableau de bord interactif pour analyser le chiffre d'affaires par catégorie de produits, la répartition des quantités vendues et les performances commerciales par ville avec Azure Maps.

🔗 [Consulter le projet et son tableau de bord](https://github.com/Youmnath/powerbi-analyse-ventes)
